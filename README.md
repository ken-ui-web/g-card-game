# Gカード・ゲーム版

既存のGカードから分岐した、独立運用のゲームアプリです。カード収集・育成・CPU戦・オンライン対戦・ランキング・テスト・学校アカウントログイン・名簿管理を残し、授業の振り返り連携を除いています。

## 元のGカードとの分離

- このフォルダーは元の `g-card` と別のGitリポジトリです。元の公開ページやコードを更新しません。
- ブラウザーのセッション、ゲスト記録、テスト下書き、トレーニング下書き、対戦記録などはゲーム版専用の保存キーを使います。
- 学校アカウントの記録には、**新しい空のスプレッドシートと新しいApps Scriptプロジェクト**が必要です。初期化時に空シートと未使用のプロジェクトを検査します。
- フロントエンドは接続先が `appId: g-card-game` を返すまでログインや購入などの操作を送りません。
- オンライン対戦には**新しいFirebaseプロジェクト**が必要です。公開前に接続先を確認します。

## 開発

```powershell
npm ci
npm test
npm run build
npm run dev
```

接続設定がない状態では学校ログインとオンライン対戦は使えません。新規バックエンドの準備と公開手順は [docs/SETUP.md](docs/SETUP.md) を参照してください。設定値と名簿はソースに入れません。
